# Mood Palettes 🎨

**Mood Palettes** is a simple color palette generator that creates color combinations based on different moods.

## ✨ Features

* Generate color palettes based on a mood.
* Simple and intuitive interface.
* Visual color preview.
* Built with vanilla JavaScript.

## 🛠️ Technologies

* HTML
* CSS
* JavaScript

## 🚀 How to use

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Select a mood and generate your palette.

## 📁 Project structure

```text
mood-palettes/
├── index.html
├── style.css
└── script.js
```

## 🎨 About

This project was created as a small web experiment exploring the relationship between **mood and color**.
